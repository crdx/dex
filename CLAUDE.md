# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

dex is a self-hosted pastebin, file hoster, and URL shortener. It consists of two applications:

- **dex** (`cmd/dex/`) - CLI client for interacting with the server
- **dexd** (`cmd/dexd/`) - Web server with API and UI

## Development Commands

```bash
just check                      # Run tests, format, and lint (use after any change)
just build                      # Build dex CLI client to bin/dex
just test [package]             # Run tests with coverage (default: ./...)
just cov [package]              # Generate function-level coverage report
just dev                        # Run development environment (hivemind + watchexec)
just generate                   # Run code generation (sqlc)
just db                         # Open database shell
just make::migration <name>     # Create a new database migration
```

## Architecture

### Key Directories

- `cmd/dex/` - CLI client (docopt-based argument parsing via duckopt)
- `cmd/dexd/` - Server application (Fiber web framework)
  - `controllers/api/` - REST API endpoints (SHA256 key auth)
  - `controllers/deploy/` - Remote deployment endpoints
  - `controllers/index/` - Web UI routes
  - `views/` - HTML templates
- `db/` - Database layer
  - `db.gen.go` - Auto-generated CRUD code (do not edit)
  - `schema/` - SQL migrations
  - `queries/` - Custom SQL queries
- `pkg/types/` - Core types (Kind, Key)
- `pkg/util/` - Shared utilities

### Database Layer

The database layer is auto-generated by Starfield (a custom sqlc plugin). Run `just generate` after schema changes.

For each table, Starfield generates:

- CRUD functions: `CreateX`, `FindX`, `FindXs`
- Column lookups: `FindXByColumn`, `FindXsByColumn`
- Update methods: `(*X) UpdateColumn(value)`
- Soft delete support when table has `deleted_at` column

### Custom Queries

Place custom SQL in `db/queries/*.sql`:

```sql
-- name: FindItemByRef :one
select * from items
where deleted_at is null
and (label = ? or uuid = ?);
```

Annotations: `:one` (single result), `:many` (slice), `:exec` (no return).

Check auto-generated functions before writing custom queries to avoid redeclaration errors.

## Starfield Configuration

Starfield is configured in `sqlc.yml`:

| Option | Description |
|--------|-------------|
| `package` | Go package name for generated code |
| `max_params` | Maximum parameters before using a struct |
| `preserve` | Table names to keep as-is (irregular plurals) |
| `rename` | Column → Go field name mapping (for acronyms like UUID, IPAddress) |

Name tables in singular form - Starfield handles pluralisation automatically.

## Shell Completions

The file `completions/dex` contains bash completions for the CLI. **This file is manually maintained**, not autogenerated. It includes custom completions such as:

- File completions for `paste` and `upload`
- Dynamic completions from `dex ls --refs` for commands that operate on items

When adding or modifying CLI commands, update `completions/dex` to match.
